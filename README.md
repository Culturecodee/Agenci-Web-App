# 🌶️ Sambal Nusantara Authentic 
### Membawa Warisan Nusantara Melampaui Batas

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=vercel)](https://sambal-nusantara-authentic.vercel.app/)
[![Project Status](https://img.shields.io/badge/Status-Active-blue?style=for-the-badge)](https://sambal-nusantara-authentic.vercel.app/)

**Sambal Nusantara Authentic** adalah platform landing page modern yang dirancang untuk memperkenalkan produk sambal tradisional Indonesia ke pasar global. Proyek ini menonjolkan nilai warisan budaya (sejak 1985) dengan pendekatan bisnis ekspor yang profesional.

---

## 📖 Ringkasan Proyek

Website ini berfungsi sebagai wajah digital bagi brand **Sambal Nusantara**, yang memadukan resep turun-temurun Jawa Tengah dengan standar higienis modern. Fokus utama platform ini adalah:
* **Branding**: Menampilkan kualitas premium dan tradisi asli.
* **Lead Generation**: Melalui formulir kontak ekspor dan pendaftaran reseller.
* **Edukasi**: Blog berisi tips dapur dan resep masakan nusantara.

## 🚀 Fitur Utama

* **Varian Rasa Unggulan**: Katalog produk interaktif (Sambal Bawang, Terasi, Matah, Ijo).
* **Reseller Gateway**: Halaman khusus peluang bisnis dengan sistem MOQ fleksibel.
* **Global Export Form**: Formulir kontak yang dioptimalkan untuk mitra internasional.
* **Responsive Design**: Tampilan yang optimal di perangkat mobile, tablet, maupun desktop.
* **Blog Masakan**: Artikel tips penyimpanan dan resep fusion (e.g., Sambal meets Pasta).

## 🛠️ Tech Stack

Sebagai pengembang, proyek ini dibangun menggunakan teknologi:
* **Frontend**: HTML, JS
* **Styling**: Tailwind CSS (Desain modern & Utility-first)
* **Deployment**: Vercel
* **Language**: Bahasa Indonesia (Support Multilingual ready)
